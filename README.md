# Hypercar Brand Data Analytics Project

This project is an end-to-end data analytics workflow based on data collected from 20 hypercar brands.

## Project Workflow

The project involved collecting and managing multiple datasets related to hypercar companies.  
Five different CSV files were created, with each dataset containing different categories of information such as:

- Brand details and company information
- Vehicle specifications
- Sales-related data
- Pricing and cost information
- Brand value and market-related metrics

The datasets were cleaned and processed using Python to remove inconsistencies, handle missing values, and organize the data into a structured format suitable for analysis.

After preprocessing, the cleaned datasets were imported into a database for structured storage and querying.

Finally, Power BI was used to design interactive dashboards and visual analytics.  
The project includes three separate Power BI canvases that present insights related to:
- Hypercar sales analysis
- Brand comparison and valuation
- Pricing and specification trends

## Technologies Used

- Python
- Pandas
- CSV/Excel Data Handling
- SQL Database
- Power BI

## Features

- Multi-dataset data integration
- Data cleaning and preprocessing
- Database storage and querying
- Interactive Power BI dashboards
- Comparative analytics of hypercar brands

## Project Outcome

This project demonstrates a complete analytics pipeline starting from raw data collection and preprocessing to database management and business intelligence visualization using Power BI.
